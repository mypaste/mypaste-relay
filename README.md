# mypaste-relay

Independent Go server extracted from the former `mypaste-code-extensions` monorepo at commit `2af6675ab1473c9e38146ea0b6da68256a293440`.

It contains `cmd/mypaste-relay`, the `relay` package, its tests, and its own Go module. It is a server, not an installable MyPaste extension package.
